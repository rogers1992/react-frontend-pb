1. Introducción

Bienvenido al Sistema Paraiso Biker

Este manual describe las funcionalidades del sistema de gestión de Paraiso Biker. El sistema permite administrar productos, inventario, ventas, compras, clientes y más.

Nota Importante

Este manual está diseñado para todos los usuarios del sistema. Si tiene dudas sobre alguna funcionalidad, consulte con su administrador.

Requisitos del Sistema

  • Navegador web moderno (Chrome, Firefox, Edge, Safari)
  • Conexión a internet para acceder al sistema
  • Resolución de pantalla mínima de 1024x768

Roles de Usuario

El sistema cuenta con diferentes roles que determinan qué funciones puede realizar cada usuario:

Rol Descripción Acceso Principal
Administrador Control total del sistema Todas las funciones
Vendedor Gestión de ventas POS, Ventas, Clientes, Productos
Inventario Gestión de stock Inventario, Almacenes, Productos
Compras Gestión de proveedores Compras, Inventario

Cómo Usar Este Manual

  • Use la tabla de contenidos para navegar a la sección deseada
  • Cada sección incluye capturas de pantalla como referencia visual
  • Los iconos ADMIN indican funciones exclusivas del administrador
  • Para imprimir este manual, haga clic en el botón "Imprimir PDF" al final de la página

2. Inicio de Sesión

Acceder al Sistema

Para iniciar sesión en el sistema:

Abra su navegador web

Ingrese la URL proporcionada por su administrador (generalmente something como http://servidor:5173)

Ingrese sus credenciales

Escriba su nombre de usuario y contraseña en los campos correspondientes

Haga clic en "Iniciar Sesión"

Si sus credenciales son correctas, será redirigido al Dashboard principal

Captura: Pantalla de Login
Imagen de referencia de la pantalla de inicio de sesión

Cerrar Sesión

Para cerrar sesión:

  1. Haga clic en su nombre/usuario en la esquina superior derecha
  2. Seleccione la opción "Cerrar sesión"
  3. Será redirigido a la pantalla de login
⚠️ Importante

Siempre cierre sesión cuando termine de usar el sistema, especialmente en equipos compartidos.

Recuperar Contraseña

Si olvidó su contraseña, contacte a su administrador del sistema para que le sea asignada una nueva contraseña temporal.

4. Productos

La sección de productos permite gestionar el catálogo de artículos de la tienda.

Ver Lista de Productos

Para acceder a la lista de productos:

  1. En el menú lateral, haga clic en "Productos"
  2. Verá una tabla con todos los productos registrados
  3. Use la barra de búsqueda para filtrar por nombre o SKU
Captura: Lista de Productos
Tabla con productos y opciones de filtrado

Crear Nuevo Producto ADMIN

Acceda a Productos

Vaya al menú Productos

Haga clic en "Agregar Producto"

Botón ubicado en la esquina superior derecha

Complete los datos del formulario

Nombre, SKU, precio, categoría, proveedor, etc.

Guarde el producto

Haga clic en "Crear" para guardar

Editar Producto ADMIN

  1. Busque el producto en la lista
  2. Haga clic en el botón de editar (lápiz)
  3. Modifique los campos deseados
  4. Guarde los cambios

Activar/Desactivar Producto ADMIN

Los productos desactivados no aparecerán en el punto de venta pero se mantienen en el historial.

  1. Busque el producto en la lista
  2. Haga clic en el botón de toggle (flecha circular)
  3. Confirme la acción

5. Categorías

Las categorías permiten organizar los productos por tipo o familia.

Gestionar Categorías ADMIN

Acceda a Categorías

Menú: Productos → Categorías

Agregar Categoría

Haga clic en "Agregar" e ingrese el nombre

Editar/Eliminar

Use los botones de acción en cada fila de la tabla

Nota

No es posible eliminar una categoría que tenga productos asociados. Primero reasigne o elimine los productos.

9. Punto de Venta (POS)

El POS permite realizar ventas de forma rápida y eficiente.

Realizar una Venta

Acceda al POS

Menú: Ventas → Punto de Venta

Busque el Producto

Use el campo de búsqueda por nombre, SKU o código de barras

Agregue al Carrito

Haga clic en el producto o presione Enter para agregarlo

Ajuste Cantidades

Modifique la cantidad si es necesario

Seleccione Cliente (opcional)

Busque y seleccione un cliente existente o registre uno nuevo

Seleccione Método de Pago

Efectivo, tarjeta, transferencia, etc.

Cobrar

Haga clic en "Cobrar" para completar la venta

Captura: Punto de Venta
Interfaz del POS con búsqueda y carrito
💡 Tip

Use el código de barras para agregar productos rápidamente. El sistema automáticamente actualiza el inventario.

Métodos de Pago Disponibles

  • Efectivo: Pago en moneda nacional
  • Tarjeta: Débito o crédito
  • Transferencia: Pago por transferencia bancaria
  • Mixto: Combinación de métodos de pago
Acceso

ADMIN VENDEDOR pueden usar el POS.

10. Historial de Ventas

Ver todas las ventas realizadas en el sistema.

Ver Historial

ADMIN VENDEDOR pueden ver el historial.

Captura: Historial de Ventas
Lista de ventas con filtros de fecha

Filtrar Ventas

  • Por fecha: Seleccione un rango de fechas
  • Por cliente: Busque por nombre de cliente
  • Por método de pago: filtre por efectivo, tarjeta, etc.
  • Por estado: Completada, cancelada, pendiente

Ver Detalle de Venta

  1. Haga clic en una venta de la lista
  2. Se mostrará el detalle completo: productos, cantidades, precios, método de pago
  3. Puede imprimir o exportar el comprobante

Cancelar Venta ADMIN

⚠️ Importante

Solo los administradores pueden cancelar ventas. La cancelación reversa el inventario.

12. Clientes

Gestión de clientes y programa de lealtad.

Ver Clientes

Acceda a la lista de clientes desde el menú.

Captura: Lista de Clientes
Tabla de clientes con información y puntos

Agregar Cliente ADMIN VENDEDOR

Acceda a Clientes

Menú: Clientes

Haga clic en "Agregar Cliente"

Formulario para nuevo cliente

Complete los datos

Nombre, apellido, email, teléfono, fecha de nacimiento

Guarde el cliente

El cliente se registrará con 0 puntos initially

Programa de Lealtad

Los clientes acumulan puntos con cada compra que pueden canjear por descuentos.

Tier Puntos Requeridos Beneficios
Bronce 0 - 499 Puntos base
Plata 500 - 999 10% bonus
Oro 1000+ 20% bonus

14. Notificaciones

Alertas del sistema para mantener informado al usuario.

Ver Notificaciones

El icono de campana en la esquina superior derecha muestra las notificaciones no leídas.

Captura: Notificaciones
Panel de notificaciones

Tipos de Notificaciones

  • Stock bajo: Cuando un producto alcanza su nivel mínimo
  • Nueva venta: Confirmación de venta realizada
  • Alertas del sistema: Información importante

  • Las notificaciones no leídas aparecen con un punto rojo

15. Gestión de Usuarios

Administración de cuentas de usuario del sistema.

Acceso ADMIN

Solo los administradores pueden gestionar usuarios.

Crear Usuario

Acceda a Usuarios

Menú: Administración → Usuarios

Haga clic en "Agregar Usuario"

Formulario de registro

Complete los datos

Usuario, nombre, email, rol

Guarde el usuario

Se enviarán credenciales temporales si está configurado

Captura: Gestión de Usuarios
Lista de usuarios con acciones

Resetear Contraseña

Si un usuario olvida su contraseña:

  1. Busque el usuario en la lista
  2. Haga clic en el botón de resetear contraseña (llave)
  3. Ingrese la nueva contraseña (mínimo 6 caracteres)
  4. Confirme la acción

Activar/Desactivar Usuario

Los usuarios desactivados no pueden iniciar sesión pero sus datos se mantienen.

  1. Busque el usuario en la lista
  2. Haga clic en el botón de toggle (flecha circular)
  3. Confirme la acción
